## Nội dung bài thực hành

Bài thực hành áp dụng các thao tác cơ bản với Git và GitHub:

- Khởi tạo Local Repository.
- Tạo và kết nối Remote Repository.
- Thực hiện commit.
- Tạo và làm việc với branch.
- Push dữ liệu lên GitHub.
- Merge branch vào nhánh chính.
